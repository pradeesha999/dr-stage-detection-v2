# Diabetic Retinopathy Stage Detection (Keras, transfer learning)

Classifies retinal fundus images into 5 DR stages
(No_DR, Mild, Moderate, Severe, Proliferate_DR).

Dataset (2.1 GB, not in this repo):
https://www.kaggle.com/datasets/sovitrath/diabetic-retinopathy-2015-data-colored-resized

Plan / progress: [PLAN.md](PLAN.md)

## Layout
```
dr_project/
  src/               reusable modules (config, data, preprocess, augment, model, ...)
  notebooks/         01_eda -> 02_preprocessing -> 03_train -> 04_evaluate
  app/               Gradio demo used for the video
  scripts/           get_data.sh (download dataset via Kaggle CLI)
  outputs/
    figures/         every plot, committed (used in the report)
    splits/          train/val/test CSVs, committed (IDs only, portable)
    processed/       cached preprocessed images  (git-ignored, regenerated by 02)
    models/          trained weights             (git-ignored)
  requirements.txt
```

`src/config.py` auto-detects the dataset at `../archive/` (local) or
`/kaggle/input/...` (Kaggle) so the same code runs everywhere unchanged.

## Environments

### A. Kaggle (main)
1. Add the dataset above to a new notebook; Settings -> Accelerator -> GPU.
2. Add-ons -> Secrets -> add `GITHUB_TOKEN` (a GitHub personal access token with
   `repo` scope) so the private repo can be cloned.
3. Paste the first cell of any notebook (the bootstrap) - it clones this repo into
   `/kaggle/working/dr_project` and `cd`s into `notebooks/`.
4. Run the notebook cells in order. Outputs land in `/kaggle/working/dr_project/outputs`.

### B. Ubuntu + RTX 3060 (experiment)
See [SETUP_UBUNTU_GPU.md](SETUP_UBUNTU_GPU.md). Then:

```bash
git clone https://github.com/pradeesha999/dr-stage-detection.git dr_project
cd dr_project && bash scripts/get_data.sh
```

### C. Windows laptop (CPU, code + report only)
`pip install -r requirements.txt`; dataset in `../archive/`; notebooks 01-02 run fine on CPU.

## Order of execution
`01_eda.ipynb` (index + split) -> `02_preprocessing.ipynb` (cache processed images)
-> `03_train.ipynb` (GPU) -> `04_evaluate.ipynb` -> `app/`.
